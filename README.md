 Arduino-Based Voltage Measurement System

 Overview
This project uses an Arduino Uno to measure analog voltage through its analog input pin (A0). The Arduino converts analog readings into voltage values and displays the results through the Serial Monitor.

 Components Used
- Arduino Uno
- Potentiometer
- Breadboard
- 1 kΩ resistors
- Jumper wires

Technical Concepts
- Analog-to-Digital Conversion (ADC)
- Voltage measurement
- Arduino programming using C/C++
- Analog input processing
- Serial communication

 How It Works
The Arduino reads an analog signal through pin A0 using `analogRead()`. The resulting ADC value is converted into an estimated voltage using a 5 V reference and displayed through the Serial Monitor.

 Results
The system successfully collected analog readings and displayed corresponding voltage measurements through the Arduino Serial Monitor.

Skills Developed
- Basic embedded systems programming
- Circuit assembly and troubleshooting
- Analog signal measurement
- Hardware and software integration
